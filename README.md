## 项目选题说明
### 第一阶段：基础素养实地测评（10选2）
- 选题1：校园微气候梯度实测与归因
  在校园3处典型点位完成早/午/晚温湿度、光照强度实测，采集原始数据并分析建筑遮挡与通风对微气候的影响。
- 选题2：校园昼夜声学噪声地图测绘
  在校园5处典型点位完成昼夜噪声均值与峰值采集，绘制噪声分布雷达图，设计基础的超标判定逻辑。

### 第二阶段：工坊开放式项目挑战（8选1）
- 选定项目：宿舍/实训室多环境监测与异常事件本地预警终端构建
- 项目目标：
  1. 基于STM32主控板搭配温湿度、光照传感器，完成底层环境数据采集终端开发，通过串口输出实时数据；
  2. 基于Linux（WSL环境）开发上位机数据接收处理脚本，实现数据自动存储、阈值判定与本地告警；
  3. 完成连续5天以上的真实环境连续监测，输出完整的过程日志与数据集。
- 技术方向：STM32嵌入式开发（C语言） + 传感器数据采集 + 串口通信 + Linux Shell脚本 + 本地阈值预警逻辑
- 预期成果：
  1. 可正常运行的STM32采集终端固件（C语言源码）
  2. Linux端串口数据接收、自动存CSV、阈值告警脚本
  3. 连续5天的环境监测原始CSV数据集
  4. 完整的开发调试日志、硬件接线记录、AI排障对话记录
  5. 验证环境数据采集、异常预警功能正常运行
